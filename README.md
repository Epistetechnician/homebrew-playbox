# Homebrew tap for Playbox

```sh
brew install Epistetechnician/playbox/playbox
```

Installs the signed release binary from <https://github.com/Epistetechnician/playbox>. Update with `brew upgrade playbox` (or `playbox update`).
The formula is generated from each release's `SHA256SUMS` by `scripts/brew-formula.sh` in the main repository.
